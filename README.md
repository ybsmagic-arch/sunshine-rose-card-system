# 陽光玫瑰抽牌系統

此資料夾是從既有公開 Netlify 網站建立的完整靜態網站備份。

## 內容

- `index.html`：網站頁面
- `styles.css`：網站樣式
- `app.js`：抽牌互動功能
- `assets/cards/`：封面與 33 張卡片圖片

## 部署到 Netlify

可直接將整個資料夾拖曳到 Netlify 的新增專案區，或先上傳到 GitHub，再於 Netlify 連接該 repository。此網站不需要建置指令；發布目錄為專案根目錄。

## 長期保存建議

1. 將此資料夾放入自己擁有的 GitHub repository。
2. 讓 Netlify 連接該 repository，自動部署 `main` 分支。
3. 保留本機或雲端硬碟的壓縮備份。
4. 正式營運時綁定自己持有並續費的網域。
